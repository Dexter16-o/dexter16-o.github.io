# Dhruv Patel — portfolio

A static, responsive cybersecurity portfolio published with GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. The site has no build step or runtime dependencies.

## Publish with GitHub Pages

1. Push the repository to its `main` branch.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. In **Actions**, open **Publish portfolio**. If its latest run did not succeed before Pages was enabled, choose **Run workflow** on `main`.

The site URL for this repository is `https://dexter16-o.github.io/Personal_Portfolio/`.

## Personalize the content

- Update the name, intro, focus topics, and contact link in `index.html`.
- Add projects only when their descriptions and links are ready to share.
- The ClipShare overview reflects its public README; replace it if you want another project featured.
- The CSS palette and shared design scale are in `tokens.css`. Page layout and responsive rules are in `styles.css`.

The portfolio uses public project information and leaves out unprovided credentials, employment history, metrics, and contact details.
